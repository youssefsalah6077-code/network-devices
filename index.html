Router
A router is a networking device that forwards data packets between computer networks. Operating at Layer 3, it reads IP addresses to make intelligent routing decisions, connecting your local network to the internet and other networks.

Network Switch
A switch connects devices within a network and uses MAC addresses to forward data precisely to the intended recipient. Unlike hubs, switches create dedicated communication channels, dramatically improving network performance and security.

Networking Framework

The OSI Model

The OSI (Open Systems Interconnection) model defines how network communication works across 7 abstract layers.

7

Application Layer

HTTP, HTTPS, FTP, SMTP, DNS, SNMP

6

Presentation Layer

SSL/TLS, JPEG, MPEG, encryption, compression

5

Session Layer

NetBIOS, RPC, SQL, NFS — connection management

4

Transport Layer

TCP, UDP — end-to-end delivery & flow control

3

Network Layer

IP, ICMP, ARP, routers — logical addressing

2

Data Link Layer

Ethernet, Wi-Fi, switches — MAC addressing & framing

1

Physical Layer

Cables, hubs, repeaters — bits over physical medium

Why the OSI Model Matters

The OSI model provides a universal language for networking professionals to describe how data travels from one device to another across a network. Each layer has specific responsibilities and communicates only with the layers directly above and below it.

When troubleshooting network issues, engineers use this model to isolate problems — "Is it a physical cable issue (Layer 1) or a routing misconfiguration (Layer 3)?"

Device-to-Layer Mapping

Hubs, Repeaters, Cables Layer 1
Switches, Bridges, NICs Layer 2
Routers, L3 Switches Layer 3
Load Balancers, Firewalls Layer 4–7
Gateways, Proxies Layer 7
Network Architecture

Network Topologies

The physical or logical arrangement of devices in a network defines its performance, fault tolerance, and scalability.

Star Topology
All devices connect to a central hub or switch. Most common in modern LANs.
✓ Easy to manage & troubleshoot
Bus Topology
All devices share a single communication line. Simple but collision-prone.
✓ Cheap to implement
Ring Topology
Each device connects to exactly two others, forming a closed ring. Data travels in one direction.
✓ Predictable performance
Mesh Topology
Every device connects to every other device. Extremely fault-tolerant and redundant.
✓ Maximum redundancy
Tree Topology
Hierarchical structure with a root node and branching sub-nodes. Used in large enterprise networks.
✓ Scalable hierarchy
